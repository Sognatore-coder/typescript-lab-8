# TypeScript: практикум (девять задач)

**Автор:** Беседин Кирилл Дмитриевич  
**Группа:** ФИТ-241


## Описание

Консольный TypeScript-проект из девяти задач: типы функций и коллекций,
перегрузки, обобщения, условные и сопоставленные типы, класс хранилища.
Каждая задача — отдельный модуль `src/taskN.ts` с реализацией и примерами вывода в консоль.

## Версии

- Node.js: v22 (LTS)
- TypeScript и `@types/node` — из `devDependencies`

## Команды

```bash
npm ci                 # установка зависимостей по package-lock.json
npm run check          # проверка типов (tsc --noEmit)
npm run build          # компиляция src/ -> dist/
node dist/task1.js     # запуск задачи
```


## Список задач и ожидаемые результаты

| Файл | Тема | Что покажет пример |
|------|------|--------------------|
| `task1.ts` | Перегрузки `formatInput` | `3.14159` → `3.14`; строка без пробелов по краям; `Date` → ISO-строка |
| `task2.ts` | Кортежи и enum | Все цвета `ColorName` с rgb и hex; `[1,2,3]` → `#010203`; **`RangeError`** для каналов вне 0–255, дробных и `NaN` (перехватывается в `try/catch`) |
| `task3.ts` | Брендированный `UserId` | Корректный UUID → профиль; некорректная строка и число → «Не является UserId» |
| `task4.ts` | Иммутабельные теги | `addTag`, `removeTag`, `mergeTags` возвращают новые массивы, исходные не меняются |
| `task5.ts` | `applyPipeline` | Цепочки из 1, 2 и 3 шагов (number → number → string → string); несовместимый пример закомментирован с пояснением |
| `task6.ts` | `reduce` | `{ paid: 300.5, free: 75 }` для смешанного набора; `{ paid: 0, free: 0 }` для пустого |
| `task7.ts` | `chunkArray` | Блоки по 3 с коротким остатком; `[]` для пустого входа; **`RangeError`** для 0, -2, 1.5, `NaN`, `Infinity` |
| `task8.ts` | `MemoryRepository<Book>` | CRUD; **ошибка** при повторном `id`; `undefined`/`false` для отсутствующей записи |
| `task9.ts` | `DeepReadonly`, `deepFreeze` | `Object.isFrozen` → `true` для всех вложенных объектов и массивов |

Ошибки (`RangeError`, повторный `id`) обрабатываются через `try/catch`,
поэтому каждый файл завершается без необработанного исключения.
